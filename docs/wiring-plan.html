5×5×5 Addressable Cube Wiring

A build plan for a 125-LED RGB cube using 4-leg addressable LEDs (APA106-F5 / PL9823-F5), driven by the existing Arduino Nano. No driver ICs, no layer transistors, three wires from the cube to the board. The structure is the one you already know from the 4×4×4: one leg stays vertical to make columns, the rest bend flat into each layer.

The idea in one picture

Every LED has four legs: DIN, VDD, GND, DOUT. VDD stays straight and is soldered to the VDD leg of the LED below it, so the 25 VDD legs in each column become the cube's vertical structure, exactly as the anode columns do now. GND bends toward the back and joins a rail running through each layer. DIN and DOUT bend sideways so each LED hands its data to its neighbour along the row.

One layer, seen from above

Each layer is a 5×5 plane built on a jig (a board drilled at 25 mm pitch, like the one for the 4×4×4). Data snakes across the layer in a boustrophedon: front row left-to-right, next row right-to-left, and so on, so every DOUT reaches the DIN beside it with the LED's own legs. GND legs all point to the back and meet a bare-wire rail; the five rails are tied together along the back edge.

The stack, seen from the side

Controller and power

Power budget. 125 LEDs × 60 mA (full white) = 7.5 A worst case. Don't buy a 10 A supply — cap it in software with FastLED.setMaxPowerInVoltsAndMilliamps(5, 4000), which scales brightness so the cube never asks for more than 4 A, and use a 5 A supply. Typical patterns draw well under 1 A.

Serial and SD. FastLED.show() turns interrupts off for ~3.8 ms while it clocks out 125 LEDs. At 9600 baud that can drop bytes arriving during an SD transfer, so the sketch must not refresh the cube while a CUBEW transfer is running. Previews are already paced by the FRAME handshake, so they are unaffected.

Build order

  1. Test every LED. Chain three on a breadboard with the Nano and FastLED's APA106 (or PL9823) type, and confirm the leg order and colour order. This is the step that saves the build.
  2. Bend to the plan. For each LED: DIN left, DOUT right, GND kinked 3–4 mm outward then to the back, VDD straight. Do all 125 the same way with a small bending jig so the layers come out flat.
  3. Build five identical layers on the jig. Press 25 LEDs into the jig, solder DOUT to DIN along each row, jumper the row ends to make the serpentine, lay a rail along each column of GND legs, and tie the five rails along the back edge. Lift out, check every joint, power it up and run a chase pattern through all 25 before moving on.
  4. Stack. Put layer 0 on the base, layer 1 on top rotated 180°, layer 2 unrotated, and so on. Solder each VDD leg to the one below to make the 25 columns — exactly the anode-column job from the 4×4×4. Use spacers (or the jig) to hold 25 mm between layers.
  5. Data jumpers. Four short wires, each from a layer's LED 24 up to the next layer's LED 0 directly above it.
  6. GND risers. A 1 mm wire down each of two opposite corners (four corners is better), soldered to every layer's tie bar, into the base GND bar.
  7. Base. +5 V bar under the 25 columns, GND bar under the risers, capacitor across them, then the Nano, diode, resistor and jack as in the schematic.

Software: mapping x, y, z to a chain index

#include <FastLED.h>
#define DATA_PIN 6
#define NUM_LEDS 125
CRGB leds[NUM_LEDS];

// x: left→right, y: front→back, z: bottom→top, all 0..4
uint8_t ledIndex(uint8_t x, uint8_t y, uint8_t z) {
  if (z & 1) { x = 4 - x; y = 4 - y; }   // odd layers are stacked rotated 180°
  uint8_t col = (y & 1) ? 4 - x : x;     // serpentine within the layer
  return z * 25 + y * 5 + col;
}

void setup() {
  FastLED.addLeds<APA106, DATA_PIN, RGB>(leds, NUM_LEDS);   // PL9823 for those LEDs
  FastLED.setMaxPowerInVoltsAndMilliamps(5, 4000);
}

The pattern file grows from 10 bytes a frame to 377 (125 × RGB + the 2-byte time), and the editor needs a colour picker instead of on/off — but the serial protocol, the SD transfer and the playlist all carry over unchanged apart from the frame size.

Builds to look at

Photos and diagrams of the same idea at other sizes, all with 4-leg addressable LEDs:

  • Cubic Art — 4×4×4 APA106 cube, 32 steps with photos: layers built on a printed jig, then stacked. The closest documented precedent.
  • Cubic Art source repository: Diagrams/Nano Wiring.pdf and Diagrams/Wiring.pdf are full wiring drawings; 3D Parts/LedCubeJig.stl is the bending/soldering jig.
  • 8×8×8 PL9823 cube, 512 LEDs: build photos and the FastLED discussion, showing the approach scales.
  • 4×4×4 PL9823 cube base (Printables): a printable base, useful for the connector and jack layout.
  • PL9823-F5 pinout photo (Surreality Labs) and their breadboard write-up: the lead order, photographed, because the listings get it wrong.
  • APA106-F5/F8 datasheet (SparkFun via DigiKey): timing, current and the DIN–VDD–GND–DOUT pin order.
